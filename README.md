# 幻想乡 · 夜境异闻

**东方 × 武侠 × 幸存者**。灵梦以御札、阴阳玉与结界退治；魔理沙以星光与魔炮开路。武侠体现在进退与取舍，不覆盖人物身份。

当前版本：`alpha-0.0.8`，角色攻击机制与符卡表现纠偏。它具有完整的开局、成长、Boss、胜败与重开闭环；不代表旧版所有功能的迁移，也尚未经过真人可玩性验收。

## 成品交付

正式交付入口为 `release/TouhouWuxiaSurvivor_alpha-0.0.8.exe`，不是源码启动脚本。
沿用旧版本的单文件口径，PCK 与 .NET 构建输出内嵌；全部旧版 EXE 保留。
版本来源为 `project.godot`，采用 `stage-major.release.optimization`，Windows 文件版本为 `0.0.8.0`。
导出命令为 `build_release.cmd`，同版本成品已存在时拒绝覆盖。下方脚本启动方式仅用于源码开发。

## 启动

工作区已有**未发布的完整设置回归**：声音、视频与十二项双键位，含画面确认回退、每页默认恢复和动态按键提示。只影响源码运行，现有 alpha-0.0.8 EXE 不包含这些改动。日常改动提交 Git；只有明确要求发布时才升级版本号并导出，推送也需单独要求。详情见 `CHANGELOG.md` 的“未发布”部分。

Windows 下双击项目根目录 `run_game.cmd`，或在本目录运行：

```bat
run_game.cmd
```

脚本自动构建新版并启动。构建与运行日志位于 `artifacts/launch-build.log` 和 `artifacts/game.log`。
本机已验证 .NET SDK 8.0.302 和 Godot Mono 4.7.1。Godot 位于其他位置时可先设置：

```bat
set "GODOT_EXE=C:\YourGodot\Godot_console.exe"
run_game.cmd
```

也可以用 Godot **.NET/Mono** 编辑器打开 `project.godot`，构建后按 F6 运行 `game/Main.tscn`，或按 F5 运行项目。

## 怎么玩

下表为默认键位；未发布工作区可在“游戏设置 → 操作”修改，Esc 始终保留安全返回。工作区 F11 切换全屏后需在 15 秒内确认，超时自动回退。

| 操作 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动，角色能力自动攻击 |
| Shift | 慢移并显示判定点与擦弹圈；魔理沙星光射击收束角度 |
| Space | 闪身，短暂无敌，约 2.8 秒冷却 |
| 1 / 2 / 3 或鼠标 | 升级时选择专属能力或通用修习 |
| Esc / P | 暂停 / 继续；子页面先返回上层，窗口失焦也会自动暂停 |
| E | 查看属性与构筑；再次按下返回原状态，升级候选不变 |
| F11 | 切换全屏 |

- **灵梦**：110 生命，追踪御札 + 阴阳玉起步，可习得驻留封魔阵；满蓄势发动梦想封印追踪灵光。
- **魔理沙**：85 生命，星光射击 + Master Spark 起步，可习得星尘幻想；移速更快，威力 +16%，满蓄势发动强化魔炮。
- 每人三条专属能力与四类公共修习，E 查看效果与出处；攻击数值与说明使用共享配置。本作按幸存者节奏改编，不是原作逐帧复刻。
- 魔炮先显示瞄准线，0.45 秒后在固定方向持续照射；可通过移动平移火线。封魔阵留在施放位置，离开不带走。
- 擦弹与退治积累符卡蓄势，满槽自动施放角色符卡，发动时清弹、短暂无敌并吸取经验。每颗弹只能贡献一次擦弹。
- 站入三处古印各七秒，获得回血与一次悟道。进度保留，遇险可以先退。古印是有价值的可选目标，不是强制门票。
- 第四分钟出现最终 Boss，击破即获胜；计时本身不会导致失败。参考自动流程约四分半，但真人通关时间取决于构筑与走位。
- 本地只保存音画偏好、最佳成绩与通关次数，没有局外数值加成。位置为 Godot `user://rebirth/profile.json`。
- 设置支持总音量、音乐、音效滑块；标题与暂停菜单可按版本查看完整更新记录。显示标题更新，内部项目名保留旧存档命名空间，继续读取此前设置与成绩。

## 新架构

```text
game/
  Main.tscn          唯一运行入口
  core/             固定步长、独立于引擎的战斗与成长
  presentation/     Godot 输入、场景绘制、HUD、菜单、音频与记录
  diagnostics/      自动化导航探针，只在明确诊断入口中使用
tests/rebirth/      编译同一核心源码的独立回归测试
tools/rebirth/      验证与截图脚本
```

主项目只编译 `game/**/*.cs`。旧 `src/`、旧测试、旧内容数据和旧工具仍在原位作为历史参考，不通过适配层参与新版运行。
重写前的完整受版本管理快照为 `d229b36`。仓库外素材和 Git 忽略的文件未加入该提交，仍保留原位。
