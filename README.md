# Touhou Wuxia Survivor

当前版本：`0.0.0-alpha`。运行时版本的唯一来源是 `project.godot` 中的
`application/config/version`；版本规则与变更记录见 [CHANGELOG.md](CHANGELOG.md)。

当前阶段是无限幻想乡生存者玩法 Demo。首个角色为博丽灵梦，当前以中文名称文字临时显示，
控制、世界生成、区块流送、自动战斗和渲染均为当前项目内的 C# 实现。

## 运行

1. 使用 Godot 4.7.1 的 `.NET` 版本打开本目录的 `project.godot`。
2. 等待 C# 项目编译完成。
3. 按 `F5` 运行主场景。

当前机器也可以直接双击项目根目录的 `run_game.cmd`。

主菜单可开始游戏、调整设置或退出。游戏内按 `Esc` 或 `P` 打开暂停菜单，
可继续游戏、调整设置、返回主菜单或返回桌面；再次按相同按键会继续游戏。

主菜单和游戏内暂停菜单均可打开“幻想乡图鉴”。图鉴可按本体或 `TH01` 至 `TH20`
筛选，并以地区、结构、敌人和角色四个分页展示内容；敌人页读取实际生命、移动速度、
出现时间、掉落率和栖息地区，并显示威胁等级、战斗定位、出场阶段和基础击破时间。
图鉴预览不是静态占位图：敌人会播放移动动作，地区会显示行人和环境活动，结构会显示
灯火呼吸与往来人物。角色页会明确区分已实现自机与尚未制作的目录角色。

移动默认支持 `WASD` 和方向键。按 `M` 打开或关闭已探索地图，地图打开时暂停世界。
地图按实际 Tile 显示地形、道路和结构细节；左键拖动，滚轮缩放，方向键平移，
固定标注已探索结构名称；鼠标移到已探索地块时，群系名称会跟随光标显示。
按 `F` 或 `Home` 回到玩家位置，
也可以按 `Esc` 关闭。游戏中默认只在底部显示窄状态栏，包含生存时间、击破数、
当前敌人数和强化。按 `F3` 切换左上角调试信息，其中显示 FPS、种子、绝对 Tile、
Chunk、当前群系、流送队列和本局内容包；调试开关可在按键设置中修改或添加第二键。

敌人会在镜头四边之外持续生成并自动追踪玩家，生成间隔和单批数量随生存时间提高；
离玩家过远的敌人会被回收。玩家自动锁定射程内最近敌人并发射子弹，无需瞄准或开火按键。
击破敌人可能掉落移速、射速或强化道具，效果均持续五秒。移速道具提供 1.5 倍移动速度，射速道具提供 2 倍射速，强化道具提供 20 倍射速、强化形态与旋转双向弹幕。玩家拥有五格生命，接触敌人会受伤并获得一秒无敌时间。玩家、敌人和掉落物暂时直接显示各自中文名称，不使用示例素材图标；对应旧图集也不进入发行包。子弹仍暂时沿用示例项目素材。
游戏页暂时沿用示例项目的开场音乐、射击、脚步、拾取、敌人受击、敌人死亡、爆炸和玩家死亡音效；开场音乐进入游戏时只播放一次，不循环。音乐与音效分别进入 `Music` 和 `SFX` 总线，可由设置菜单的三个音量滑块实时控制。

生命归零后游戏立即暂停并显示死亡弹窗；可直接返回主菜单，或进入本局总结查看生存时间、
击破数、最终群系与坐标、启用内容和世界种子。总结页支持重新开始或返回主菜单，两个操作
都会先清除死亡暂停状态，主菜单不会继承上一局的暂停状态。

Windows 发行版使用 `build_release.cmd` 生成到 `release/TouhouWuxiaSurvivor.exe`。导出预设采用 x86_64 Mono Release 模板、内嵌 PCK和内嵌 .NET 构建产物，发行目录不需要独立 PCK；窗口与 EXE 图标来自 `assets/branding/icon.png`。
沿用 `start-game` 示例素材，但代码和资源副本均位于本项目，不对参考工程产生运行依赖。

设置保存在 `user://settings.json`，包括主音量、音乐、音效、双键位绑定、窗口模式、
窗口分辨率、垂直同步和帧率上限。地图开关默认仅为 `M`，可以在设置中修改或添加第二键；
按键页可一键恢复全部默认绑定。

## 本体与正作内容包

点击主菜单“开始游戏”会先进入本局内容选择。幻想乡本体始终启用；不勾选任何正作时，
世界只生成本体地区、结构、通用敌人、道具和系统。本体内容层当前标记为已完成：

- 地区：幻想乡原野、博丽神社、人间之里、魔法森林、妖怪之山
- 结构：博丽神社、结界庭院、人间之里、魔法阵遗迹、山间梯田、荒野十字路
- 敌人：野妖精、毛玉、妖虫、阴阳玉、森林精怪、山精、流窜妖怪、夜行妖怪、大妖怪
- 角色与道具：博丽灵梦、移速道具、射速道具、强化道具
- 系统：无限世界、群系敌人生态、随时间增强刷怪、自动战斗、旅行地图、死亡结算

敌人由实际生成位置的群系决定，森林精怪、山精和流窜妖怪分别属于对应地区；夜行妖怪和
大妖怪在生存时间达到要求后加入所有地区。选择列表中的 `TH01` 至 `TH20` 均已完成第一阶段
运行时接入并可独立勾选：每一作加入三个可生成地区、三个会在地图标注的结构和三类
只在所属地区刷新的特色敌人，共计六十个地区、六十个结构和六十类正作敌人。启用多个作品时，
这些内容会共同分布到无限世界，而不是互相覆盖。

各包清单还列出了代表角色，供后续制作自机、敌人和首领；这些名字当前是内容目录，不代表
对应角色已经拥有可操作或首领战实现。`迷途竹林`、`竹林古道`和`竹叶妖`严格归属
`TH08 东方永夜抄`，不勾选该作时不会泄漏进本体世界。

每个整数编号正作都拥有 `content/packs/thXX_slug` 独立目录和 `pack.json`；清单按地区、
结构、敌人和角色分类列出增量名称。包内预留 `actors`、`world`、`assets` 边界，
小数编号外传暂不归入正作目录。

## 世界尺度

- `1 Godot unit = 1 px`
- `1 Tile = 16 x 16 px`
- `1 Chunk = 32 x 32 Tiles = 512 x 512 px`
- 默认保留玩家周围 `5 x 5 Chunks`

生成结果只取决于世界种子和绝对 Tile 坐标。玩家远离本地原点后按整 Chunk 重定位，
避免 Godot 浮点坐标和 `TileMapLayer` 坐标范围导致精度下降。

## 像素渲染规范

所有 2D 纹理默认使用最近邻过滤，所有 PNG 禁止生成 mipmap，并启用 2D 变换与顶点像素对齐。
新增角色、结构、弹幕、特效和 UI 图片应继承项目默认过滤；不要在场景节点上覆盖为 Linear。
`TexturePolicySmokeTest` 会递归审计运行时场景和纹理资源。

武侠界面使用项目内确定性 RGB 绘制器生成宣纸纹理、卷轴九宫格边框、祥云分隔、朱砂印章、
墨山背景以及动态图鉴精灵表。资产说明和重建命令见 `assets/ui/wuxia/README.md`；敌人曲线、
威胁模型与刷怪节奏的策划基线见 `docs/enemy_balance.md`。
