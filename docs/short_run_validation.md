## 失败证据与修正

1. 首次新增测试的 Check 名称被顶层测试函数遮蔽，编译失败；改为与既有测试相同的显式检查入口，保留 core-initial.log。
2. 首轮基础玉轨道扩大让近身流收益倒退；保留原回旋半径，依靠增加玉数量体现升级。药菇末重补足可感知跨度；休整测试排除无关自动攻击，Boss 禁锢测试改为验证休整移动与蓄势不停摆。保留 core-r1.log；之后全部 74 项通过。
3. 照搬旧经验曲线时首领前最多约 27 次成长，首领也过早结束；改为有限经验预算与 24000 首领生命，未给路线加锁或增加强制无敌，保留 balance-r1.log。
4. 第一份 Web 候选在魔理沙 180 档出现 Tick=855 的一帧 Choosing，被原压力门槛正确拒绝；其 FPS 与模拟速度本身合格。根因是夹具只在下一帧前解决选卡，快节奏经验更早触发升级。新增诊断 CompleteStep，在帧结束时完成自动选卡；普通游戏仍暂停，未注入新恢复、修改种子或放宽门槛。补每步恰好推进一 tick 且输出 Playing 的回归；重建后完整复验通过。
5. 最后复核将环幕指示线内收，通道测试从只查中心扩展到两侧边界，给弹体与玩家半径保留可走余量。

原生坏存档提示来自刻意构造的恢复测试；Web 导入日志也保留音频导入时的 UTF-8 提示。本轮未修改原作音频。浏览器运行期检查无报错。
