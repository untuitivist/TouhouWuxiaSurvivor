# 幻想乡 · 剑雨异闻

> 2026-09-06 重写版的唯一当前设计。旧设计是历史资料，不是验收清单。

## 一句话

在博丽结界破碎的五分钟里，以飞剑迎击妖潮，穿行弹幕积蓄剑意，在三处古印之间取舍路线，最后击破雾中来客。

## 好玩的核心

1. **走位有回报**：自动攻击让注意力留给敌阵。擦过敌弹积蓄剑意，满槽自动爆发并清弹；闪身可以穿险，但冷却期间必须规划退路。
2. **升级改变打法**：御剑负责定向穿透，阴阳阵负责近身回旋，灵符负责范围爆破，雷法负责远距连锁。满级武学获得形态变化；基础属性仅作为补充选择。
3. **地图给出目标**：三个古印在明确方位，停留净化可回血并获得一次悟道。赶路、留守和迎敌互相竞争，而不是无目的绕圈。
4. **节奏有起伏**：普通妖潮逐渐加入远射、冲锋和精英；四分钟后召唤最终 Boss，以可读的扇形、环形弹幕完成收束。失败也给出本局成果和立即重开。

## 这次实际制作的范围

- 单张有限战场：博丽夜境；场景有道路、古印、鸟居、树木和边界。
- 两名角色：灵梦生命与擦弹见长；魔理沙移动和进攻见长。角色选择直接说明差异。
- 移动：WASD / 方向键；Shift 慢速精确移动；Space 闪身；Esc 暂停；升级按 1/2/3 或鼠标。
- 四门可成长武学和四类通用修炼；所有升级从同一个定义表生成界面和效果。
- 无局外数值碾压；本地只记录音量偏好、最佳成绩和通关次数。
- 菜单、角色选择、操作说明、暂停、三选一、胜败结算、音效和音乐控制。

## 战斗规则

- 固定 60Hz 模拟；伤害、生成与随机数独立于 Godot 渲染帧率。
- 玩家具有清晰的小判定点；敌弹比光晕小，慢移时显示擦弹圈。
- 每颗敌弹仅能贡献一次擦弹；擦弹不等于受伤，不允许同一弹反复刷取。
- 闪身提供短暂无敌，不作为必须连按的输出技能。
- 三选一时彻底冻结模拟；连续升级逐次处理，选择不得越级或重复应用。
- 精英掉落恢复物；经验自动近距吸取，净化古印可收拢经验。
- 精英于 55、110、165、220 秒出现；240 秒召唤终局来客。Boss 生命为 26,000，按 66% / 33% 生命切换弹幕。
- Boss 有入场提示及三段随生命变化的弹幕；计时不会直接判玩家输，击破才胜利。
- 使用有上界的敌人/弹丸/视觉反馈集合；不把大量节点当作每颗弹的必要载体。

## 工程边界

- `game/core/`：纯 .NET 模拟、数值与升级定义，无 Godot 引用。
- `game/presentation/`：输入、绘制、音频、界面和本地持久化。
- `game/Main.tscn`：唯一新入口；主项目只编译 `game/`。
- `tests/rebirth/`：直接引用同一核心代码的无第三方测试可执行程序。
- 不增加内容包市场、地图编辑器、无尽模式、装备背包或联网功能。
- 保留旧代码与素材以便回退，但不通过适配层调用旧系统。

## 验收与诚实边界

- 必须编译通过、核心回归通过、Godot 无界面运行通过、真实渲染截图检查通过。
- 当前参考结果：19 项核心回归通过，6 次未注入生命或伤害的导航机器人流程均于 263.7–279.8 秒获胜；该结果仅证明一套策略能完整通关，不代表最终难度已定。
- 测试覆盖固定步长、随机可复现、暂停/升级冻结、擦弹单次记账、闪身冷却、升级上限、Boss 胜利与重开隔离。
- 自动化只能检验运行正确性与数值边界，不能替代真实试玩来证明“好玩”。
- 使用仓库已有内部原作素材；此交付不是可公开发行的授权声明。
