# 幻想乡 · 夜境异闻

> 当前设计：alpha-0.0.9，2026-09-06。历史版本的变化见 CHANGELOG.md；人物资料与原作出处见 docs/character_identity.md。

## 方向与边界

东方 + 武侠 + 幸存者。武侠是人物行事、进退、距离与取舍，不是给所有人套剑、雷法或修仙身份。东方人物的身份、能力和符卡语汇优先。当前只制作灵梦与魔理沙，不把全量资料库存当作完成度。

每项恢复内容都判断玩家价值和更好的实现方式；新机制同样接受审视。保留熟悉操作，不机械复刻旧架构，也不为了缩小实现范围抹掉人物差异。

## 单局体验

在博丽夜境中自动退治、穿行弹隙，决定如何成长、是否净化三处古印，四分钟后击破结界残影。移动与构筑选择为主，不增加必须频繁按下的主动攻击键。

- WASD / 方向键移动；Shift 慢移与判定点显示；Space 闪身。
- Esc/P 暂停；E 查看构筑，关闭返回原状态；1/2/3 或鼠标选升级。
- 查看、暂停和连续三选一期间，弹丸、场地效果、光束前摇与持续时间全部冻结。
- 每人三条专属能力、四类公共修习；近满级时可出现恢复选项，不混入另一个角色的攻击。
- “重”是能力成长等级，不宣称人物改修某门武侠功法；公共修习只调整威力、频率、生存和游走。

## 灵梦：从容走位与驻留控场

- 初始追踪御札 + 阴阳玉。御札转向追敌，目标死亡后重新索敌；阴阳玉绕身接触攻击与击退。
- 封魔阵为可习得第三条能力：附近有敌人时在当前位置留下方形阵地，按固定脉冲伤害阵内敌人。走开之后阵仍留在原地。
- 满符卡蓄势自动施放灵符「梦想封印」的本作转译：七枚七色追踪灵光，命中后局部爆破；不是公共圆形伤害换了名称。
- 御札、阴阳玉与封魔依据来自原作说明书与符卡资料。具体弹速、寻敌、驻留与数值都是本作实现，不声称逐帧复刻。

## 魔理沙：星屑覆盖与定向火力

- 初始星光射击 + Master Spark。星弹为直线散射，Shift 收束角度，但不增加弹数或伤害，不等同于灵梦的追踪弹。
- 星尘幻想为可习得第三条能力：向四周散布星屑，贯穿两敌，以覆盖与近距密度区别于集中射击。
- Master Spark 自动寻找方向，先显示 0.45 秒无伤害瞄准提示，再持续发射有限长度和宽度的光束。光束按 0.12 秒脉冲命中前方区域，并清除光束中的敌弹。
- 光束方向在启动时锁定；玩家仍可移动，调整整条火线的位置。伤害与宽度随重数成长，施法精进仅缩短休整，不加快脉冲或前摇。
- 满蓄势启动更宽、持续 2.4 秒的强化 Master Spark，替代当前普通施放周期，不叠出无限光束。
- 星屑、光热魔法、八卦炉魔炮与符卡名均有资料依据；自动施放、预警、固定方向等是幸存者转译，不当作各原作一致的规则。

## 共通节奏与存档

- 固定 60Hz 模拟。每颗敌弹只贡献一次擦弹；退治也增加符卡蓄势。
- 符卡发动保留清弹、短暂无敌和经验吸取，作为本作共同安全窗口；这不表示两位角色原作符卡的效果完全相同。
- 三处古印净化进度可保留，完成后回血、悟道并收拢经验；它们是可选目标，不是终局门票。
- 四轮精英与 240 秒终局到来沿用此前框架。结界残影是本作原创异变敌人，不再把通用 Boss 直接假托为魔理沙。
- 无永久局外数值加成。旧音量偏好、成绩继续读取；不保存进行中的构筑，因此新能力 ID 不需要迁移旧局内存档。
- 显示名称改为“夜境异闻”，而 project.godot 的 application/config/name 保留旧字符串作为稳定的存档命名空间。WindowSetTitle 设置新窗口标题，避免更名挪走 user://。

## 结构与验收

- ArtCatalog 记录角色归属、来源与成长说明；AbilityTuning 提供攻击和数值预览的共享参数。
- 初始能力、升级候选和选择应用均遵循角色归属。基础碰撞/查询可以共用，但攻击行为不能为复用而失去人物特征。
- 御札、阴阳玉、驻留方阵、星弹、星尘、魔炮与梦想封印需要真实可辨识的绘制；危险敌弹绘制在玩家攻击效果之上。
- 保留标题/暂停中的完整历史日志、三路音量、E 构筑与原状态返回。各能力在构筑页和三选一标注出处与本作转译。
- 本轮已有 26 项核心测试与 UI/旧记录兼容检查；自动导航可完成两位角色的胜利流程。具体渲染、成品与隔离结果记录在 docs/rebirth_validation.md。
- 自动测试通过不等于更好玩；真人需要重点检验魔炮锁向是否烦躁、阵地是否值得利用、星弹收束是否形成选择，以及符卡是否足够可读。

## 仍然暂缓

无限地图、全作品库存迁移、完整图鉴、局外永久数值成长、无尽模式与 Web 移植。不声称本轮修复这些功能，也不因为当前未制作就认定它们没有价值。素材仍仅用于内部开发验证，不由此推断具备公开发行授权。

## alpha-0.0.9：完整设置

- 日常提交与推送、发布分离。完整设置现随 alpha-0.0.9 发布，既有 alpha-0.0.8 EXE 不被覆盖。
- 三页分别负责声音、画面、操作。音量、静音、减少震屏与改键即时保存；画面模式/窗口尺寸/VSync/FPS 在 15 秒确认后保存，超时或取消恢复上次确认值，未应用草稿离页丢弃。
- 三种显示模式：普通窗口、保留任务栏的无边框最大化、全屏。七档窗口尺寸从 640×360 到 3840×2160，逻辑视口保持 1280×720。帧率限制只影响渲染，不更改固定模拟步长。
- 十三项当前操作（含 F3 诊断）各有两个物理键位，至少保留一个。冲突明确拒绝，不默默抢占其他操作。Esc 保留安全返回，Tab/Delete 用于界面，组合键、鼠标与手柄重绑不在本轮范围。
- HUD 与界面提示从同一份输入配置生成。捕获键位优先于暂停/全屏；三选一优先于 UI 确认；子页面、画面预览均不穿透操作，也不消耗待选升级。
- 继续使用 user://rebirth/profile.json 的 schema 1，增量补齐视频和键位字段，保留已有成绩/偏好；旧 user://settings.json 不自动导入、不删除。每页重置不会清除其他页或成绩。

## alpha-0.0.9：像素视觉与只读诊断

- 菜单使用暖纸/木框/朱红书签/草绿选中，战斗保持暗底与危险色。PixelSkin / PixelTheme 管理所有可交互状态，32px 原始皮肤最近邻放大，PixelLandscape 生成 320×180 原创夜景；不使用《夜雀食堂》的界面素材。
- 标题字形硬边，中文正文保留灰度抗锯齿。像素风不以牺牲文字可读性为目标；640×360 仅保证布局可用，默认 1280×720 更适合阅读。
- F3 参照 Minecraft 的信息覆盖层组织方式，不复制三维区块/作弊命令。DebugOverlay 只读取当前运行与引擎监视器，四次/秒更新文字、每可见帧记录间隔；隐藏时停止采样/格式化。托管堆、Godot 静态内存、引擎耗时分别标注，不混称总内存或 GPU 性能。
- debug action 与其他操作同目录、同存档、同冲突规则，捕获输入优先于切换。叠层不拦截鼠标，不暂停或改变胜败/待选状态，也不写成绩和存档。
