# Reimu Growth Sample

## Scope

2026-09-08：本轮实现灵梦小型成长样板，不升版、不导出正式 EXE、不推送部署。魔理沙保留已有玩法；不将她的初始魔炮安排误称为已迁移的基础攻击成长树。

## Playable Rules

- 初始只有直射御札。阴阳玉和封魔阵在升级中解锁；梦想封印是修习等级 5 起可选的一次解锁，未解锁时蓄势仍能积累但不会自动发动。
- 御札：每轮保留一发准确朝目标发射的直射符，其他符向两侧扩展，不额外增加弹数。追踪使弹丸转向并重新索敌，代价为单札伤害减少 20%；爆炸向半径 64 内最多 4 名其他敌人造成 35% 单札伤害，不重复伤害直击目标。两者可兼修，溅射基于追踪减伤后的伤害，不递归触发；梦想封印不继承普通符的爆炸。
- 阵：默认在脚下驻留。聚敌选点在 600 范围内取至多 32 个有效敌人位置，用空间网格估计覆盖数，只在施放时计算；不是每帧全局最优搜索。禁锢随阵伤害脉冲施加 0.5 秒，普通敌人停止位移，首领速度为原来的 55%，攻击时钟继续。
- 玉：每轮环绕伤害脉冲共享 3 发消弹预算，不是每枚玉各 3 发。自动蓄力 0.8 秒后发射一玉，可贯穿三敌，飞行时少一枚护身玉，1.4 秒后归位；下一次蓄力有 5 秒基础间隔。发射玉具有独立且有限的 3 发消弹预算。
- 六个行为节点需要对应能力已获得且修习等级至少为 3。每个仅一次；不冲突的节点自由兼修，顺序不改变最终构筑。精进只增加对应能力重数，不赠送未选择的行为。
- 三选一无重复且过滤前置、归属和上限。灵梦优先保留一个可用能力解锁和一个可用行为选项，其余从合法池补齐；不足时提供调息。本轮没有亲和权重、重掷、容量上限或新增互斥。

## Boundaries

- UpgradeDefinition / UpgradeCatalog：稳定 ID、归属、前置和文案。BuildState：重数、已领悟行为与投入点数。UpgradeOffers：低频候选规则。
- ReimuAbilitySystem：灵梦战斗行为；ReimuAbilityState：计时状态。批量敌人与弹丸继续使用现有 ECS 数据容器，菜单保留 OOP。
- 阴阳玉环绕位置与数量由核心共用函数计算，画面与碰撞不各维护一套；消弹先于玩家碰撞处理，不依赖弹丸在容器中的插入顺序。
- 升级、构筑、暂停、结算和原有图鉴能力详情使用同一组行为定义。图鉴仍为 22 个内容条目，分支放在所属术式详情，不虚增条目。
- 复用原作御札、阴阳玉、阵纹与光环；没有新画素材。后续新画/修改只能使用本机 Aseprite，保留源文件。

## Balance Pass — 2026-09-08

用户追加要求数值平衡。首轮发现偶数扇形没有中央弹，远处静止单体可能被全部漏过；同时追踪爆炸在密集场景过强。因此先修正直射瞄准，再加入追踪伤害代价与爆炸目标上限，而非提高其他能力来追赶失控倍率。

固定 6 点投入、30 秒、固定高血量静止/移动目标，不计控制和消弹价值：

| 场景 | 纯精进 | 追踪爆炸 | 聚集禁锢阵 | 消弹发射玉 |
| --- | ---: | ---: | ---: | ---: |
| 远处单体 DPS | 110.93 | 391.42 | 104.67 | 43.33 |
| 远处密集群 DPS | 332.77 | 939.67 | 916.00 | 96.00 |
| 贴身环形群 DPS | 678.60 | 958.10 | 917.33 | 1495.47 |

修改前追踪爆炸密集群 DPS 为 2821.15（约阵的 3.08 倍）；修改后为 939.67（约 1.03 倍），而阵额外提供控制。阴阳玉保留近身优势和有限消弹，不强行抹平远程输出差异。追踪仍明显擅长单体命中，纯精进不再出现静止远处目标零输出。

三种路线优先策略各运行六个相同种子，18 局均通关，没有额外注入回血；这些是同一自动驾驶器的结果，不是玩家胜率估计。后期会补入其他能力，因此不能把终局胜率当作纯路线强度证明。记录完整早期选择、逐分钟状态、生命与通关时间，便于后续复测。

复现：dotnet run --project tests/rebirth/Rebirth.Tests.csproj --configuration Release -- --growth-balance。原始前后报告见 artifacts/growth-balance-before.json 和 artifacts/growth-balance-after.json；增加宽松的相对守护断言，防止再次出现基础漏靶、爆炸全面压过阵、玉失去贴身优势。
