# 卡片式图鉴回归

## 旧版审阅

旧版 src/ui/compendium 使用六类枚举（群系、结构、敌人、角色、构筑、符卡）、作品筛选、ItemList 和并排详情。CompendiumCatalog 聚合领域目录，CompendiumEntry 保存不可变事实与素材来源。保留数据来自玩法目录、区分设定与素材出处的设计，不直接重新编译旧 src 或移植其已停用的玩法清单。

## 本轮范围

- 标题、触屏标题与暂停菜单均提供“夜境图鉴”。
- 六类：行者、术式、修习、符卡、妖怪、夜境；共 22 项当前已实现内容，另有“全部”筛选。
- 每页六张素材卡片，点击进入独立详情。详情返回保留分类、页码与选中卡片的键盘焦点。
- 详情支持滚动、复制、上下阅读按钮；触屏无需精确拖动细滚动条。Esc 先退回卡片，再返回来源菜单；暂停中浏览不会恢复战斗。
- 卡片和详情使用局内已有原作素材；精灵条只裁第一帧静态预览，保持比例。纹理按路径缓存，浏览期间不跑独立战斗或动画。
- 修习图标复用阵纹并明确标注；精英与终局精灵共用现状不掩饰，不额外绘制占位美术。

## 数据与维护

JournalCatalog 提供稳定英文 ID、分类、摘要、详情与素材路径。角色基准读取独立 RunState，敌人零时刻样本走现有 SpawnEnemy，术式逐重效果读取 ArtCatalog 与 AbilityTuning。静态构建只发生一次，不引用或修改正在进行的战斗。

图鉴数值是当前玩法投影，不是原作数值。描述性的玩法说明仍需随机制变更审阅；素材路径公开用于内部检查，原始素材来源继续由 assets/internal_original 内现有清单保存。

## 暂不恢复

旧版多群系、多结构、全作品包、图鉴解锁与收集奖励不随 UI 自动回归。作品筛选当前没有对应的已启用作品目录，暂不放置空筛选器；不把原作素材出典当作可玩 DLC。历史目录与文档全部保留。

## 验证

原生 JournalDiagnostics 覆盖条目 ID、当前术式同步、所有预览资产、分类与页码、详情返回焦点、暂停安全。Web 使用真实按钮点击验证桌面及手机横屏布局，不等同于手机真机测试。本轮日常提交，不升版、不推送、不发布。

- 原生回归：tools/rebirth/verify.cmd。
- 本地兼容 Web：build_web.cmd -Threadless，再运行 tools/platform/verify_journal.cmd。
- 原生截图入口：--rebirth-screen=journal 或 journal-detail，配合现有 --rebirth-capture 参数。
- 预览边界回归：全部 22 项缩略图固定 80×80，详情固定 240×216，父框裁剪；禁止纹理原始尺寸撑开控件。
- 显示设置预览取消后恢复原详情，不跳回标题或暂停。
