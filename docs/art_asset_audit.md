# 原作战斗美术接入清单

## 本轮判断

用户给出的素材包中确实存在可用的魔炮、星光和阵纹。此前基础星弹已经使用原作裁图，但魔炮本体、蓄力五角星、封魔阵和古印主要仍由直线、多边形、圆弧组成。这是接入与美术完成度不足，不能归因于用户没有提供素材。

原则是先检索、看图和验证用途，再决定裁切、透明度、混合模式与动画组合；不能只按文件名猜用途，也不因能用程序画一个形状就省略素材接入。保留功能性判定、进度与预警标记，不把它们冒充完整特效。

## 合成与可读性

- 原始灵梦阵纹含中性白底；直接混合会形成遮挡场景的整块图案。去底版本保留 RGB，仅将原透明度乘以 `red - min(green, blue)`，提取原图红色纹样，不重新绘制符号。原始裁图保留供核对。
- 魔炮单独使用加色层，封魔阵、纸符和一般光效使用普通透明层；不让所有特效共享一种不合适的混合方式。压低魔炮叠加曝光，保留炮身纹理和发射端星环。
- 阵纹尺寸跟随原有方形范围，魔炮长度和主体宽度跟随原有能力参数；外围光晕只是装饰。原有伤害、碰撞、弹数、前摇、持续时间及移动规则不变。
- 特效时序与颜色层次是本作演出，不声称逐帧复刻原作。减少动态效果时关闭新增星环、阵纹旋转及魔炮色相变化；暂停继续冻结游戏时钟与已保留的绘制结果。
- 使用最近邻采样；素材在初始化时缓存，不在每帧读取文件，不把高频弹丸改回逐实体 Node。角色主特效位于敌人与敌弹之下，原有判定点、危险提示和净化进度仍保留。

## 尚未替换

- 标题背景 `PixelLandscape`、场景树木与鸟居仍有程序绘制，不能把本轮写成整体美术已原作化。
- UI 框架、血条、净化进度、判定点和范围预警是功能性图形，不在本轮重做菜单或删除可读性标记。
- 当前仅更换已确认用途的战斗特效，不扩角色、不修改人物能力、不顺便改架构或玩法数值。
