# 单主线成长设计：有限定式，持续精进

> 状态：讨论稿，未实施。日期：2026-09-12。查阅源码基线：f616d3a（本轮设计前的 HEAD），不是对线上版本的实时验证。
>
> 本轮只写设计和交流记录，不改玩法、数值、素材、存档、版本或游戏更新日志，不构建、导出、推送或部署。接受设计讨论不等于授权实施。

## 1. 先给结论

**一局把一种打法修深，而不是迟早把所有打法收齐。**

建议先让每名角色只有一条主要成长线、一个真正影响打法的二选一定式；已选定式内部可以继续学相容效果和反复精进。其他能力仍能解锁、组合，但暂不扩成另一个完整主线。先验证这两种打法确实不同，再考虑增加下一处分叉。

这不是给多条主线分配“核心槽”“专精名额”，也不是把追踪和爆炸这种相容效果强行拆开。有限的是一局能够采用的作战方式，不是规定人物只能有一种攻击。

## 3. 现状：为什么不能只把时间调长

| 查到的事实 | 对本次设计的影响 |
| --- | --- |
| [RunState](../game/core/RunState.cs) 的 BossArrival 为 240 秒；[RunProgression](../game/core/RunProgression.cs) 在击杀 Boss 后立即进入 Won | 当前是第 4 分钟出 Boss，不是固定第 5 分钟结束；通关后不能直接继续成长 |
| [BuildDefinition](../game/core/BuildDefinition.cs) 根据角色、等级、能力前置重数和上限判定可选，行为以标记累加 | 有前置，但没有记录选择哪一侧定式、排除另一侧的规则 |
| [UpgradeCatalog](../game/core/UpgradeCatalog.cs) 优先给一个可用解锁，再给行为或修习选项 | 比较容易不断横向开能力；拖长流程本身不会产生长期取舍 |
| 灵梦开局只有御札，魔理沙开局只有星流；其他攻击、药菇和蓄势符卡需要解锁 | 不用为了成长树把已经做到的“基础攻击起步”再推倒一遍 |
| 魔理沙已有增质、变谱、长明的重复修习；[MarisaTuning](../game/core/MarisaTuning.cs) 同时有采样安全界限、范围和容量界限 | 重数能继续增加，不代表每一次都还有相同收益，更不代表无限实体或无限数值精度 |
| 净化会额外给一次选择，并不等于升一级 | 规划选择预算时必须连净化一起计算，不能只看人物等级 |

**设计判断：**如果只增加前置层数、减少经验或推迟 Boss，而所有节点始终开放，足够长的一局仍会全修。必须把“选择另一种打法”和“把现在的打法练强”分开。这是规则推断，不是已经完成的乐趣测试。

## 4. 成长结构

### 4.1 三类内容，各有职责

- **主线定式：**改变核心攻击的工作方式，同组二选一，本局不能兼得。选择后另一侧及其专属后继关闭；下一局重新选择。
- **相容技法与辅助：**追踪、爆炸、控场、护身、回血、魔炮等。保留解锁与有限精进，可以服务任一定式；不设置额外武器栏或核心点货币。
- **持续精进：**强化当前主线的伤害、质量分布、寿命或仍有实际收益的参数。不能通过高重数偷偷获得另一侧定式。

首轮每个角色只新增两个定式效果，不同时铺四五条大树。定式之后先利用现有技法和数值维度形成深度，不为树看起来庞大而添加一串“伤害 +1%”前置。

这意味着首轮每人只有两种主要打法，不宣称已经有足以支撑任意时长的新鲜感。若重复精进很快变得无聊，要先检查分叉和遭遇是否真正改变决策，而不是继续加时长或空白重数。

### 4.2 什么可以兼修，什么必须取舍

- 追踪改变飞行，爆炸改变命中结果，两者能组成同一张符，因此继续兼修。
- 阵的聚敌选点与禁锢，玉的消弹与发射，魔炮的追敌、广域与共鸣，都不因本稿被强行拆开。
- 定式争用的是同一个核心规则：一次发札按稳定连发还是蓄后集中；一个星体的额外撕扯优势放在新生期还是成熟期。两种完整规则不能直接叠加。
- 机会成本负责标准局内“先学什么、是否补辅助”；定式排除负责长局乃至续战中“始终不能全拿”。两者不能互相代替。
- 可以最终学齐所选定式允许的有限配件；不要求每个小配件永远缺一块。但另一侧的核心打法始终不能获得。

暂不做局内洗点或切换定式。首次选择需要清楚展示放弃项并轻确认，避免误触；这是建议规则，不是已经修改操作。

## 5. 标准局节奏建议

首轮以**第 18 分钟终局 Boss 登场、约 18–22 分钟完成**为测试目标。失败可以更早，强弱构筑的击杀时间可以不同，不用计时器强制把每一局凑够 20 分钟。时长指实际战斗模拟时间，不包含选卡、暂停和查看构筑。

| 阶段 | 累计成长选择目标 | 体验与压力变化 |
| --- | --- | --- |
| 0–3 分钟：认识基础攻击 | 3–5 次 | 基础怪为主，尽快获得一次看得见的改善；首次定式开始出现，不用熬十分钟才分路线 |
| 3–7 分钟：形成打法 | 7–10 次 | 定式与一两项相容技法开始配合；用冲锋怪、远程怪和精英的组合测试走位与清怪缺口 |
| 7–12 分钟：补缺或继续专注 | 12–17 次 | 给愿意绕路净化的玩家机会，但不强制完成；交替出现密群、分散远程与精英压力 |
| 12–18 分钟：使用成型构筑 | 20–26 次 | 保留数分钟真正使用构筑；高压与短暂回收经验窗口交替，不持续把屏幕堆满 |
| 18 分钟起：终局验证 | 不强行冻结成长 | Boss 与受控的杂兵支援检验单体、移动和生存；击败后进入胜利选择 |

选择次数包含正常升级和净化奖励，不是 20–26 级再额外送若干选择。它是经验与遭遇调试目标，不是硬等级上限，也不保证所有玩家、所有路线恰好相同。

### 拉长的是决策与战斗变化，不是等待

- 不把当前 240 秒线性增长公式直接放大到 1080 秒。不同阶段分别安排怪物组合、精英时点、弹幕密度和回收窗口。
- 复用已有敌人和场地；先改变组合与时序，不同时要求新地图、新怪物和大量新美术。
- 难度至少交替考验移动单体、稀疏远程和密集近战，不能让一条路线在全部场景都占优。
- 阶段推进不要求清空所有敌人，净化不是通关门票；也不靠无限刷精英奖励制造额外成长。
- 敌人质量按可解释的敌人/阶段定义设置，不实时追着玩家抽出的重星加质量，不能让 Boss 永远比玩家更重。
- 到实体预算后限制新生成，压力主要由组合和行为承担；不靠无限加怪拖垮 Web，也不以突然堆血伪装新内容。

## 6. 灵梦样板：御札主线

保留巫女、御札、阴阳玉、封魔阵与梦想封印，不换成剑或雷术。武侠感来自出手节律、近远距离和退进，不来自换武器。

	直射御札（初始）
	  ├─ 相容技法：追踪、爆炸；可兼修
	  └─ 发札定式（二选一）
	       ├─ 疾札：均匀连续出手 → 沿此节律精进
	       └─ 叠札：自动积蓄后集中出手 → 沿此节律精进
	  辅助：封魔阵、阴阳玉、梦想封印；仍需解锁

| 定式 | 行为与长处 | 必须保留的代价 | 相容效果 |
| --- | --- | --- | --- |
| 疾札 | 较短的发札间隔、较低的单次威力，持续补伤，转移到新目标后恢复输出快 | 不获得叠札的集中爆发；单次伤害和单位命中的溅射需要一起计价 | 可学追踪与爆炸；阵创造持续输出机会，玉帮助穿行 |
| 叠札 | 仍自动攻击，把输出集中到间隔更长的札阵释放；玩家在间隙走位，释放时获得明显反馈 | 有真实输出空档和过量伤害风险，不获得疾札的无缝压制；积蓄不强制站定 | 释放时按原有规则瞄准，学追踪后弹丸继续追踪，爆炸仍能兼修 |

两侧按相同投入比较完整周期 DPS，不把“连发更快”或“每次更多符”直接当免费收益。追踪的命中收益、爆炸覆盖及现有不递归限制也要计入，不能只平衡面板单札伤害。

定式从后续施法生效，不回收或重算已经发出的符；选择升级也不立即免费补发一轮，避免把菜单时点变成额外爆发来源。

后续候选围绕符威、该定式的出手效率和有效命中能力展开。速度、弹数、追踪与范围有实用及性能边界；接近边界后不再推荐虚假效率升级，转向仍有效的符威等精进。不能把两侧间隔都压到同一个下限，最后又变成完全相同的连射。

**两个完整例子：**疾札 + 追踪 + 爆炸 + 护身玉，偏向持续游走补伤；叠札 + 追踪 + 爆炸 + 禁锢阵，偏向用控制窗口集中清退。辅助只是例子，不是绑定：疾札也能学阵，叠札也能学玉。

## 7. 魔理沙样板：星流主线

沿用[魔理沙成长设计](marisa_growth.md)已经明确的物理和人物边界：少量多次四方散星、独立质量抽样、多对多引力、近距离持续撕扯、有限药菇续航与魔炮输出。

	四方逐颗散星（初始）
	  ├─ 共通精进：撕扯强度、增质、变谱、长明
	  └─ 星流定式（二选一）
	       ├─ 星潮：新生阶段更强 → 游走接敌、经营新星的覆盖
	       └─ 星域：成熟阶段更强 → 引敌回到已有星场、经营驻留
	  辅助：药菇、魔炮、满蓄势魔炮；仍需解锁

这里不拿“增质”和“寿命”做互斥项，也不设计“轻星路线禁止出重星”。**两侧抽样与引力规则相同，取舍的是星体在生命周期中何时更有输出优势。**

| 定式 | 行为与长处 | 必须保留的代价 |
| --- | --- | --- |
| 星潮 | 新生星的早期撕扯获得较高增益，随后回到普通强度；仍是持续伤害，不变成碰撞爆炸。换位置接敌时能较快建立有效输出 | 不取得星域的成熟高收益；留下的旧星不会永久保持新生增益，离开星场也不会让旧星传送到身边 |
| 星域 | 新生星不享受星潮的提前强化，随星龄进入较高但有界的成熟撕扯阶段；适合把敌人引向已经存在的星场 | 有建立星场的时间成本；换场后不能立即获得同等成熟输出。较重星能否出现仍取决于抽样，不能靠选分支送一颗 |

强势曲线属于同一个定式配置，不能用两个可累加标记同时开启。年龄窗口及幅度由后续数值验证确定；反复精进不能把新生优势延伸成全寿命最高倍率，也不能把成熟等待压成零，从而抹掉分叉。

### 绝不借成长重做偷偷改掉的规则

- 每颗星独立从分布抽样，不设总质量池、不归一化、不保底大星、不指定行星名额；质量、分布和寿命维度对两侧都开放。
- 引力继续由真实质量参与计算；星与星、星与附近怪物保留多对多作用，不换成单目标吸附或由定式硬选目标。
- 星体出生后的质量和到期时间不因升级重抽或刷新；定式生涯参数建议也在出生时确定。新定式、新寿命及分布只影响之后出生的星体，界面需说清生效时点。
- 高质量仍可能影响 Boss；困难来自质量差、运动与成长成本，不加 Boss 专属免疫或永远追赶的质量门槛。
- 伤害是少量多次，不能因“牧师式续航”就允许同投入总 DPS 明显落后灵梦；比较方法见验收部分。
- 星星保持原作多色素材，魔炮保留流动炫彩。选星潮不把星星画成雷电，选星域也不擅自改成黑洞素材。

**两个完整例子：**星潮 + 增质/变谱 + 追敌魔炮，偏向移动中不断接敌；星域 + 长明/增质 + 留药与共鸣魔炮，偏向围绕既有星场调动敌人。两侧都能选全部共通精进，不能把示例变成强制配装。

## 8. 辅助不是第二条完整主线

| 能力 | 值得保留的作用 | 首轮不扩展的部分 |
| --- | --- | --- |
| 灵梦的封魔阵 | 在脚下或敌群处创造输出窗口，保留禁锢与选点兼修 | 不新增独立阵法终局树、专属无限叠层或替代御札的第二套主线 |
| 灵梦的阴阳玉 | 护身、有限消弹、自动蓄力发射，兼顾近身反击 | 不以无限玉数量换成长，不取消发射后的护身空档 |
| 魔理沙的药菇 | 调整走位与恢复机会，保留留药/缓释 | 不加入无限吸血、无上限储药或满血永久护盾 |
| 魔理沙的魔炮 | 持续火线、范围补伤、与星流共鸣、有限消弹 | 暂不新增魔炮独立无尽树；不是把它删成无伤害装饰 |
| 两人的蓄势符卡 | 已解锁后的周期性强反馈和安全窗口 | 不在开局白送，也不允许频率成长抹去全部危险时间 |

既有辅助解锁、相容行为和有限精进先作为保留基线；具体数值以后按主线目标审查，不预先宣布全部删除或合并。魔炮的追敌依旧是自动瞄准最近的存活敌人并转向，不是跟随移动方向。

不设置“最多只能解锁一个辅助”的名额。常规局通过投入取舍，续战允许逐渐补齐辅助，但辅助没有另一套无限终局。验证主线确实承担主要持续输出，而不是在程序里硬把辅助伤害限制为总伤害的某个百分比。

## 9. 升级选择怎么给

### 定式出现时

建议在**第四次实际成长选择**展示两侧定式：开局赠送的基础攻击不算投入，升级与净化给予的选择都计入。不要求先把攻击堆到很高重数，不依赖随机抽中另一张前置才能看到路线。

沿用三张卡：定式 A、定式 B、一张标注“暂不定式”的普通精进。第三张正常获得所写收益并消耗本次选择，不是免费重抽。选择暂缓后，下次仍能看到两侧；定式一旦选定，不再出现另一侧。未定式时基础攻击照常工作，不直接判失败，但暂时缺少定式收益。

这保证关键决策可见，也避免靠运气刷不到路线。两侧都直接解释所得、代价、保留的兼修能力和“本局另一侧关闭”。

### 定式确定后

- 至少提供一张当前主线仍有效的成长卡；不足时不伪造收益或复刻两张同卡。
- 其余位置从相容技法、有限辅助、通用补缺中抽取；仍过滤角色、前置、重数和定式排除，再进行无放回抽样。
- 取消“每次尽量先塞一个新能力解锁”的固定优先级，改为随阶段与已选内容调整倾向；亲和不等于永远只出同一张伤害卡。
- 三张卡不必固定成“输出/防御/辅助”三个槽；否则表面三选一、实际只有一张能继续主线。
- 有至少三个合法选项时给三张不同的卡；不足时如实给较少选项和有效调息，不用重复卡假装有选择。满血调息不得成为唯一可继续游戏的空白升级。
- 多次待选逐次结算，每次按新的构筑重新生成并校验；不能从旧菜单队列捞出已经被关闭的兄弟定式。

本轮不同时新增重掷货币、排除次数、商店和装备槽。先让原有三选一本身成立。

## 10. 怎样持续成长而不退化成空点

**持续成长是局内沿已选方向仍有有效投入，不是无限技能栏，也不是无限局外永久加攻。**

### 收益曲线原则

1. 有限技法会学完，但已选主线仍有可重复精进；精进不会解锁被放弃的定式。
2. 伤害、质量中位数等先快后缓，逐步降低相对收益，不让所有维度固定百分比相乘迅速失控。
3. 质量可以继续向更高值成长，不能用总质量池兜平衡。候选曲线如 median(n) = m0 × (1 + a × n)^p，其中 a > 0、0 < p ≤ 1；只是可测试方案，不是本轮改动，也不是已经平衡的参数。
4. 变谱不是纯外观：扩大分布可能改变均值、稀有重星概率及实际伤害，需单独测分位数和多种子收益，不能按零输出成本计算。
5. 发射频率、半径、弹数、控制、回血、消弹与减伤必须有明确边界；不允许无限频率、无限实体、百分百免伤或永久禁锢。伤害等其他维度承担后续成长。
6. 数值达到计算精度或设计安全边界后，停止把该项作为有增益的升级发放，并说明原因；不是显示“又升了一重”却实际被截断。

### 星体容量是必须正面说明的取舍

现有 96 星容量与基础 0.18 秒发射间隔，忽略其他回收时，约 17.28 秒寿命就会接近满载。加快发射还会更早遇到容量。因此“寿命更长 = 星星无限变多 = 输出永远增加”不能成立。

首轮建议保留满载跳过本次出生的保护，不偷偷合并质量、替换最老星、刷新寿命或把漏发攒成齐射。界面应说明长明增加驻留时间，但满载时换星变慢；星潮尤其需要把这个代价显示出来。

- 长明仍是可以选择的驻留策略，不以容量为借口取消寿命成长；不把它包装成无代价增伤。
- 给出在场/容量、当前发射间隔、寿命及近期被容量阻塞的生成情况；普通卡用简明说明，详细数据放构筑/F3。
- 长明与效率的推荐要结合已有投入；已受容量制约时，继续提供有效的撕扯/增质等替代项，不强迫玩家反复加寿命。
- 若试玩证明满载策略破坏两种定式，先单独讨论生命周期方案；不能未经确认引入用户否定的质量池或保底规则。

数学上的无限精度和设备上无限运行都无法据本稿承诺。后续先验证标准局和延续到 45–60 分钟的实际成长，极端重数再做边界测试；两者不冒充彼此。

## 11. 胜利后继续：推荐，但仍待确认

建议标准 Boss 胜利后给两个选择：**结算退场**、**继续挑战**。这是同一局构筑的自愿延续，不要求为了正常通关玩无尽，也不默认把流程改成永远没有结尾。

- 击败标准 Boss 时记录本次标准通关；继续后保留定式、重数和已解锁辅助，被放弃的定式仍关闭。
- 续战建议每约 5 分钟形成一轮压力变化与短暂整理窗口，经验和有效精进继续供给；不再反复赠送第一次净化的奖励。
- 难度按明确阶段提升，不看玩家抽到重星就同步上调怪物质量，不用只涨生命值或无上限生怪延长战斗。
- 每轮结束可退出，暂停界面也应允许主动结束挑战；保留已获得的标准通关记录，续战失败不把它改写成标准局失败。
- 续战成绩单独记录时长/轮次与本局定式，不兑换永久战斗数值；旧历史成绩不凭空归类为某条新路线。
- 暂不扩展跨设备云存档、排行榜或完整中途保存。移动端后台恢复与页面重载会影响长局体验，未来是否做局内续存需单独确认，不能暗示现在已经支持。

先验证标准局能成型且有差异，再实现同构筑延续。不是先塞无尽按钮，再靠玩家多玩几十分钟掩盖前半局无聊。

## 12. 选择与查看界面

- 沿用三选一、键鼠/触屏、暂停和 E 构筑习惯，不增加必须手动瞄准或反复按下的战斗键。
- 普通卡说明本次实际变化；定式卡额外写明“获得什么 / 不再获得什么 / 哪些仍可兼修”，颜色不能是唯一识别方式。
- 定式轻确认不穿透到下一次升级；连续待选、暂停、查看图鉴时所有战斗、蓄力、星龄和寿命时钟一起冻结。
- 构筑页只突出“当前定式 → 已学技法 → 下一步可学/已放弃”，细节点击展开。不为本轮先造一个占满手机屏幕的大型树编辑器。
- 图鉴保留另一侧的可读说明并标记本局不可选；它是信息，不是解除排除的入口。中英文共享同一规则与参数来源。
- 设置、原有按键绑定、音量、成绩与历史更新日志保留；界面素材继续原作优先、需要绘制时使用 Aseprite，不开展新一轮全美术重画。

## 13. 将来实现时的解耦边界

这里只描述职责，不新增类、不移动现有代码，也不以“重构”为名重写全游戏。

| 层次 | 应负责 | 不应负责 |
| --- | --- | --- |
| 内容定义 | 稳定 ID、角色、前置、定式组/选项、相容标签、收益与文案键 | UI 文案中隐藏排除逻辑，或每处复制一套数值 |
| 局内构筑与候选规则 | 已选定式、重数、有效收益、选择校验、独立可复现的候选随机序列 | 菜单过滤了就算安全；实际应用时不再次检查 |
| 角色战斗规则 | 定式对应的出手/星龄曲线，原有追踪、爆炸、引力与魔炮行为 | 每帧解析菜单文案或遍历整个成长树 |
| 遭遇与胜负流程 | 阶段、刷怪预算、标准胜利、续战与结算 | 随玩家构筑即时作弊式补质量或添加隐藏免疫 |
| 表现与平台 | 从同一结果展示卡片、图鉴、构筑与反馈；适配输入/存储 | Web 与 EXE 各实现一套成长与概率 |

低频的定义、菜单和规则编排继续用清晰的对象结构；大量敌人、弹丸和星体继续使用现有密集组件、空间查询与批量更新。无需把每张卡做成 ECS 实体，也不为每颗星新增场景对象。定式选择时计算可复用配置，战斗热路径只读必要参数。

新增定式身份不能只依赖累加行为标记；“选了哪一侧”必须能被核心规则校验。旧设置/历史数据采用可选字段兼容，不改存档命名空间，不给旧成绩补造路线记录。若以后加入局中存档，再单独规定旧局加载与版本迁移。

## 14. 验收清单：现在是计划，不是测试成绩

| 范围 | 需要证明的事情 |
| --- | --- |
| 路线可达性 | 两侧都能在预定成长机会看到，不依赖随机抽到冷门前置；暂缓会继续成长而不锁死 |
| 永不全修 | 从任一侧开始，即使持续选择大量合法升级，也不能取得兄弟定式或其后继；拒绝绕过菜单直接应用非法选择 |
| 相容性与顺序 | 追踪/爆炸、阵选点/禁锢、玉消弹/发射及魔炮相容行为顺序独立；前置与跨角色过滤仍生效 |
| 候选质量 | 有效主线成长不被辅助池挤掉，无重复；饱和参数不谎报收益；净化和连续升级不使用过期候选 |
| 长流程 | 分别记录每次选择的来源、战斗时间、成型时点和 Boss 登场/击杀时间；验证 18–22 分钟及 20–26 次目标，而不是默认成立 |
| 定式区别 | 相同角色、相同投入与辅助，在移动单体、稀疏远程、密群、转场场景中比较；若只剩颜色/面板差异或一侧全面更强，定式设计不通过 |
| 双人平衡 | 相同实际选择次数，解锁和辅助也计价；比较相近攻防投入而不是一方全输出一方全回血。保留既有单体 DPS 比值 0.8–1.2 的基准检查，并看群伤、命中、建立输出时间和整局表现，不拿单张静止靶表代替平衡 |
| 随机与引力 | 多种子统计质量分位数和伤害，验证独立抽样、没有保底/总量池，重星影响 Boss 仍可能；升级不重抽已有星体、不刷新寿命 |
| 持续成长 | 45–60 分钟实际运行加极端重数边界检查；无溢出/NaN、无满场永生星靠刷新续命、无常驻无敌/消弹、无“显示升级但没有变化” |
| 性能与双端 | 两角色和两侧定式、最长有效寿命、满容量引力/弹幕、开关菜单及无共享内存 Web 全覆盖；保留原有压力门槛，记录实际实体构成、设备与渲染 FPS，不以核心模拟步耗时冒充浏览器或手机帧率 |
| 胜利与历史 | 标准通关和续战结果分别正确结算，续战败北不抹通关；旧设置、成绩、日志与操作回归 |

原有“1000 实体、60 FPS”目标不能因本次拉长流程被静默降低。测试必须说明实体种类、数量、设备和浏览器；本轮没有重新运行性能门禁，也没有新增任何手机真机通过的结论。

真人试玩还需要回答：第三分钟是否已经在做选择？成型后是否有足够时间使用？哪次升级改变了走位？两侧是否愿意各玩一局？这些不能用自动驾驶胜率替代。

## 15. 建议实施顺序与本次交付边界

如另行确认实施，建议依次推进：

1. 先做定式身份、相容规则、有效重复精进、饱和提示与候选/卡片说明；用现有短流程验证两侧可玩且不互相吞并。
2. 再扩展阶段与经验节奏到标准长局；保持敌人/美术范围，先平衡构筑成型和使用时间。
3. 最后接入自愿续战与独立结算记录，扩展极端成长和容量验证，完成双端、长局和真人体验验收。

这是设计内部的实施次序，不是把完成一份设计稿等同于完成了游戏功能。持续成长的收益检查须贯穿前两步，不能留到最后才发现整条路线已在容量上限空转。

本稿建议优先讨论三点：**18–22 分钟是否适合作为标准局目标；疾札/叠札与星潮/星域是否形成你想要的取舍；是否采用标准胜利后自愿续战。**其余次数与曲线随这些方向的验证调整，不先锁死。
