# 魔理沙：星群、魔炮与药菇

目标版本：alpha-0.1.8。发布包含同源 Windows 单 EXE 与 threadless Web；实际构建提交、产物哈希与线上启用记录以该版本 release/RECEIPT_alpha-0.1.8.json 为准。

## 玩法与边界

- 初始只有引力星群。药菇、魔炮和满蓄势强化魔炮需要修习解锁；兼容分支可同时学习。
- 本作定位为低单次爆发、持续撕扯、走位牵引与药菇续航。魔理沙仍为使用星光、魔法与 Master Spark 的魔法使；这里的辅助定位不改写原作职业。
- 各星在生成时独立随机质量，之后保持稳定；不设整组或全场质量池，不进行归一化。单星伤害独立结算，增加星数不会分走其他星体质量或伤害。质量改变范围和牵引，伤害、数量与持续时间各自成长。
- 无逐星场景节点、无全量两两物理相互作用。一次生成一组、最多四组，32 星体硬上限；星体死亡/敌人死亡不刷新寿命。当前常规最大在场数为六星乘四组，即 24。

## 三条成长路线

| 路线 | 精进 | 可兼修分支 |
| --- | --- | --- |
| 引力星群 | 单星基础 DPS 从 8 到 14 | 增质：每星质量 ×5/3；星群 4→6 颗；长明 +1.4 秒；行星 |
| 药菇调合 | 每份恢复 6→14 HP | 留药：上限 3→5、寿命 +16 秒；缓释：额外一半药量，2 HP/s、队列上限 18 |
| Master Spark | 光束宽度、持续时间及单脉冲伤害 | 追敌：平滑转向最近存活敌人；广域：宽度 +60%；共鸣：火线内星体撕扯 +25%；限量消弹 |

星群每 1.7 秒生成，基础存续 3.8 秒，撕扯周期 0.15 秒；生成整组失败时不插入半组、不消耗随机分配。普通星独立随机质量 1.2–4.8；行星独立随机质量 6–10，在抵达落点后聚怪，不消耗其他星体质量；增质对每星乘 5/3，数量变化不改变此分布；引力合力封顶 125 单位/秒，首领系数 0.12，精英系数 0.45。每星每次最多作用 12 个伤害目标，优先保留实际锁定目标，避免高密度杂兵遮断首领输出。

药菇每 11 秒生成一次，基础保存 22 秒，不随施法速度或伤害倍率加速。满血不浪费拾取物，过期回收；局内和图鉴均使用素材包中 TH17.5 东方刚欲异闻/data/sprite/marisa/mushroom000.gif，经 Aseprite 原色转换到 assets/internal_original/base/combat/marisa_mushroom.png；来源校验记录在同目录 marisa_mushroom.source.json。此前自绘尝试保留在 art/aseprite/marisa/，但不进入运行时素材目录。

魔炮基础持续 2.25→3.25 秒，脉冲伤害 9→17，间隔 0.12 秒，休整 4.2 秒；蓄势 0.45 秒无伤害/消弹/共鸣。追敌角速度上限 180°/秒，复用 RunState.NearestEnemy 在 1200 范围内选择最近存活敌人；每步重选，不按敌人体量加权。停步也会追踪，新近敌人出现或当前目标死亡会换目标；无目标或与目标重合时保留有效方向。未学追敌时整次魔炮保持起射方向。共鸣不增加质量、分裂次数或寿命，不形成递归放大。强化符卡保留解锁与发动安全消弹。

## 模块职责

- BuildState / UpgradeCatalog：OOP 角色构筑、先决条件、兼修和参数说明。
- MarisaAbilitySystem：调度；MarisaProjectileSystem：密集星体生命周期、独立质量采样、局部持续伤害与牵引；MarisaBeamSystem：光束；MarisaHerbSystem / PickupSystem：有限药量与拾取。
- CombatWorld.Stars 保存 StarBody 连续组件。EnemyGrid 提供局部候选，下一次敌人移动消费有上限的牵引速度；渲染复用现有星光批次，新药菇只有一个批次。
- Windows 与 Web 编译同一 game/ 目录，不维护第二套玩法。

## 新机制验证边界

- 修正后的核心 56/56、本地化 997/997 和等点数靶场通过。新增独立质量/增星不摊薄/每星伤害与最近敌人追踪测试，覆盖停步、目标移动、最近目标切换、死亡、超出范围和重合目标；没有沿用旧固定质量池的 55/55 成绩。
- 修正后三组无额外回血自动旅程：魔理沙 315.3–320.2 秒胜利，灵梦 278.8–285.9 秒胜利。旧魔理沙 360.3–375.4 秒成绩仅作历史证据；自动走位与靶场不等于玩家平衡结论。
- 初轮最近目标策略导致首领战超过 420 秒；普通星的引力目标改为有限范围内距离/体量加权（不用于魔炮瞄准），不用简单加伤害掩盖问题。原始失败测量保留于 artifacts/marisa-gravity-20260911/。
- 实际 Windows/Web 画面、触屏、跨源隔离缺失、压力档和发布回执需在最终产物上记录；未测试真实手机/平板，不承诺所有设备恒定 60 FPS。
