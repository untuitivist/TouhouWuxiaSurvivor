# 临时选人 AI 立绘

本目录仅为用户批准的选人界面临时例外；一般美术仍采用 Aseprite＋原作素材。这里的内容是 **AI 原图的 Aseprite 裁切／透明背景提取，不是重绘作品**。

## 文件

- `reimu.aseprite`：博丽灵梦。
- `marisa.aseprite`：雾雨魔理沙。
- 两者均为 520×800、单帧，包含隐藏锁定的原图裁片层和可编辑的前景层。
- 原始 1536×1024 设定板在仓库根目录 `ai-assets/`，原样保留；裁切区域为 `(16, 140, 520, 800)`。
- 可见像素保持原图颜色和原始分辨率；只进行轮廓／背景遮罩和零碎背景清理。图中原有姿势不重新生成或描绘，技能说明不作为玩法需求。
- 运行时文件：`assets/ui/portraits/ai-preview/reimu.png`、`assets/ui/portraits/ai-preview/marisa.png`（相对仓库根目录）。只供选人页加载，局内和图鉴不使用。

## 手动修改

1. 用 Aseprite 打开相应 `.aseprite`，修改可编辑前景层；原图裁片层保持隐藏，供对照使用。
2. 保存源文件，再使用 Aseprite 的导出功能将可见层导出到对应运行时 PNG，保持 520×800 画布与透明背景。
3. 不要把参考层一起导出。两端共用这两个 PNG，打包入口均包含该目录。

`tools/aseprite/extract_hero_portraits.lua` 记录本次提取方法，遇到已有源稿或 PNG 会拒绝覆盖。需要重做提取时提供新的 `output`／`textures` 目录，不能用它覆盖手工改稿。

`tools/aseprite/verify_hero_portraits.lua` 用于验证**未经手改的本次提取**：原图像素来源、图层状态、PNG 与源稿一致。主动改色／重绘后，应更新来源说明，而不是把此提取校验继续标为通过。
