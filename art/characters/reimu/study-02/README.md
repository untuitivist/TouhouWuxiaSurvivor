# 灵梦重绘样板 02：人体与服装

状态：新绘制的单姿势立绘样板，待用户视觉审查；不是已批准素材，不是战斗动画，未接入游戏。

## 可手动编辑的源文件

- reimu.aseprite：主源文件，192×288，24 个可编辑图层，1 帧。建议从这个文件继续手动修改。
- anatomy.aseprite：同坐标的人体结构稿，包含身体体块、轴线和关节标记，方便检查动作。
- comparison.aseprite：三栏展示板（人体结构、服装剪影、上色稿），仅作查看，不作为人物修改入口。
- 同名 PNG：对应源文件的预览导出。layers.json 记录初次交付的图层名称、可见性与不透明度；手改后它不会自动同步。

## 图层用法

主文件没有合并成一张图片。图层自下向上大致分为：

| 名称前缀 | 内容 |
| --- | --- |
| 00 Hair / Gohei | 后发、御币，位于人体后方 |
| 01a / 01b | 弯曲腿与支撑腿的人体底层 |
| 02 / 03a / 03b / 04 | 胸廓腰胯、两侧手臂与手、头部体块 |
| 06a / 06b | 两侧鞋袜，独立于腿部 |
| 07 / 08 / 09 | 腰带尾部、衬裙、外裙与褶皱 |
| 10 / 11 | 上衣、腰带和结饰 |
| 12a / 12b / 12c | 两侧袖子、覆盖衣服前方的叉腰手 |
| 13 / 14 | 面部底色、五官 |
| 15 / 15b / 16 | 头顶与刘海、两侧发束、发带 |
| 00 Construction overlay | 最上方的半透明人体辅助层，默认隐藏，打开眼睛图标即可对照 |

图层内仍包含相应部件的轮廓和明暗，不是每一根线都独立成层。可继续在部件上方新增修正层。源文件没有锁定图层。

## 手改优先与防覆盖

1. 在 Aseprite 打开 reimu.aseprite，修改后正常保存；需要留多个版本时另存新文件，不覆盖你想保留的稿件。
2. PNG 预览使用 Aseprite 的导出功能更新，不要为了更新 PNG 重跑初稿生成器。
3. 生成脚本 draw_reimu_anatomy.cmd 默认检测已有源文件并拒绝覆盖；初稿 Lua 不是手改后的权威来源。需要另起设计稿时，指定全新的 STUDY_OUTPUT 目录。
4. 后续代理必须先检查工作区和源文件变化，保留用户手改；不得通过重跑脚本、恢复 Git 文件或旧 PNG 反向覆盖源稿。
5. 此目录位于 art/characters 的 Godot 忽略范围内，不参与游戏资源导入。立绘与战斗精灵仍需分开设计，不直接缩小此稿替换 48×48 帧条。
